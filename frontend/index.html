Quick Start Guide

Follow these steps to prepare your files for upload:

  1. Export your preprocessor: 
    import joblib
preprocessor = StandardScaler()  # Or your preprocessor
preprocessor.fit(X_train)
joblib.dump(preprocessor, 'my_preprocessor.joblib')
  2. Export your model: 
    import joblib
model = RandomForestClassifier()  # Or your model
model.fit(X_processed, y_train)
joblib.dump(model, 'my_model.joblib')

After uploading your files, integrate with your application:

import requests
import json

API_URL = "https://data2api.onrender.com/pipelines/predict"
TOKEN = "your_auth_token"  # From login response

headers = {
    "Authorization": f"Bearer {TOKEN}",
    "Content-Type": "application/json"
}

payload = {
    "preprocessor_filename": "my_preprocessor.joblib",
    "model_filename": "my_model.joblib",
    "input_data": [{"feature1": value1, "feature2": value2}]
}

response = requests.post(API_URL, 
                        headers=headers,
                        data=json.dumps(payload))

predictions = response.json()["predictions"]
print(predictions)
